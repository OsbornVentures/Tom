# Contributing to Tom

Report the Tom version, operating system, relevant CPU/RAM/GPU details, reproducible steps, expected behavior and actual behavior. Keep examples small and synthetic. Do not post session URLs, keys, private conversations, screenshots with personal information or raw task journals.

For code changes, follow [the build guide](docs/BUILD.md), keep changes focused, and run the relevant checks. Model behavior needs separately recorded trials with prompts, configuration and failures; passing unit tests is not evidence of model accuracy.

Contributions to Tom’s original source are under Apache 2.0. Preserve dependency notices and do not add weights, installers, credentials or user state to Git. Discuss major dependency or architecture changes in an issue first.
