Observed September 11, 2026. Small, developer-visible tasks on one Windows computer. These are release checks, not a general AI accuracy or coding score. No failures were replaced with retries.

Run one inference trial at a time with interactive Tom unloaded. Local tasks allowed 24 steps/12,288 generated tokens/10 active minutes; the core suite allowed 16 steps/10,000 generated tokens/10 active minutes. Ordinary desktop activity continued; elapsed times are indicative. Scoring checked saved bytes or independently specified outcomes. Model-written tests alone were not accepted as ground truth.

The core scorer’s old browser-result accessor was normalized after inspection to understand current action records. Neither browser trial actually read a source, so the correction changes no pass/fail outcome. The saved evidence retains those failures.

## Earlier E2B Q4 comparison

The [September 6 comparison](e2b-capability-2026-09-06/REPORT.md) contains 64 trials across four modes on eight tasks, two seeds each. The earlier Tom passed 6/16 artifact checks; Aider passed 14/16. It used an earlier harness, two threads and Q8 K/V cache. Do not combine its denominator with this release, attribute changes solely to the model, or claim a general win over another harness.

The useful focus remains short local work, explicit inputs and outputs, small data transformations and simple image questions. Complex software repairs, long tasks, context preservation and web browsing need further work. There is no SWE-bench, broad repository, physical 8 GB or clean-hardware score here.
